# BSc Thesis (Mortality in Poland 2000-2020)

The objective of project entitled 'Mortality in Poland 2000-2020' was to investigate the causes of this phenomenon on the basis of actual data taken primarily from the statistical office database, but also from other knowledge bases concerning Poland over the previous 20 years and more. The attached code was used to create all statistics, rankings and plots used in the project. Attached was also the environment with all loaded variables after running a code.
